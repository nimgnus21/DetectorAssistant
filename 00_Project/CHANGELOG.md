# Changelog Policy

The changelog follows the principles below:

- Record only meaningful project changes.
- Maintain chronological order.
- Never delete historical records.
- Use Semantic Versioning (Major.Minor.Patch).
- Every official release must have a corresponding changelog entry.

Each release should document:

- Added
- Changed
- Improved
- Fixed
- Removed (if applicable)
