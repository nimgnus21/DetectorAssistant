# Home

> iDetector Home Module

---

# 1. Purpose

The **Home** module is the default landing page of the iDetector software.

It provides an overview of the current software status, detector status, and commonly used operations. This page serves as the starting point for daily detector operation and system monitoring.

---

# 2. Scope

This module documents the functions available on the **Home** page of iDetector.

The documentation includes:

- Home page overview
- Status information
- Shortcut functions
- Notification area
- Navigation

---

# 3. Functional Overview

The Home page provides centralized access to system information and commonly used functions.

Typical functions include:

- Software status
- Detector status
- Recent operations
- Shortcut entry
- System notifications

Actual interface elements shall follow the corresponding iDetector software version.

---

# 4. Main Components

Typical areas of the Home page include:

- Header
- Navigation panel
- Status panel
- Shortcut area
- Notification area

Each component is documented in its corresponding document when applicable.

---

# 5. Operating Principles

The Home page is primarily used for:

- Checking detector status
- Confirming software status
- Accessing frequently used functions
- Viewing important notifications
- Navigating to other software modules

Most engineering operations begin from this page.

---

# 6. Related Modules

The Home module links to the following software modules:

- Detector
- Acquire
- Calibrate
- SDK
- Settings
- Upgrade
- Log
