# Export Log

> iDetector Software Module - Export Log

---

# 1. Purpose

The **Export Log** function is used to export software log records generated by iDetector.

Exported log files are primarily used for:

- Technical support
- Engineering troubleshooting
- R&D analysis
- Customer issue reproduction
- Software debugging

Exporting logs preserves the original operation records for subsequent analysis.

---

# 2. Scope

This document describes the log export function provided by the iDetector software.

The export function saves collected log information to files that can be archived or submitted for technical analysis.

The available export format depends on the software version.

---

# 3. Function Overview

The Export Log function allows engineers to save current log records outside the software.

Typical exported information may include:

- Software operation records
- Detector communication records
- SDK messages
- Warning messages
- Error messages
- System operation history

---

# 4. Typical Usage

Log export is recommended in the following situations:

- Detector connection failure
- Image acquisition failure
- Calibration failure
- Firmware upgrade failure
- Software exception
- SDK error
- Customer technical support
- R&D issue investigation

---

# 5. Operating Procedure

Typical workflow:

```text
Open Log Module

↓

Review Current Log Records

↓

Select Export Log

↓

Choose Save Location

↓

Save Log File

↓

Verify Export Completed
```

The exact interface and operation may vary depending on the software version.

---

# 6. Engineering Recommendations

Before exporting logs:

- Reproduce the issue whenever possible.
- Complete the operation before exporting.
- Do not restart the software unless necessary.
- Preserve the complete log sequence.

After exporting:

- Keep the original file unchanged.
- Store the exported log together with issue documentation.
- Archive logs if long-term analysis is required.

---

# 7. Information to Submit

When sending exported logs to technical support or R&D, it is recommended to include:

| Item | Description |
|------|-------------|
| Detector Model | Detector model |
| Detector Serial Number | Detector SN |
| Software Version | iDetector version |
| SDK Version | SDK version |
| Firmware Version | Detector firmware version |
| Problem Description | Description of the issue |
| Reproduction Steps | Steps to reproduce |
| Exported Log File | Original exported file |

Providing complete information helps improve troubleshooting efficiency.

---

# 8. Notes

- Do not modify exported log files.
- Do not delete original logs before analysis is complete.
- Export logs immediately after the issue occurs whenever possible.
- Keep exported logs together with other diagnostic information.
