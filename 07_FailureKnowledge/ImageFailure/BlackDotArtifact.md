# 1. Phenomenon

图像中出现黑点类异常伪影。

---

# 2. Field Handling

1. 保存异常图像。
2. 连续采集多幅图像，确认黑点是否固定。
3. 按产品适用流程检查并重新执行相关校正。
4. 重新采图验证。
5. 若现象持续，保留原始图像与现场信息后升级分析。

---

# 3. Diagnostic Note

本节点用于记录图像中的黑点类伪影。是否属于固定 Defect、校正异常或其他原因，应根据重复性和校正后的验证结果继续区分。
