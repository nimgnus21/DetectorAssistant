# 图像与现场异常现象知识库

> 用途：用于异常图像分析、现象识别、候选原因排序和证据补充。
>
> 核心原则：**单张异常图像只确认“现象”，不直接确认 Root Cause。** 必须结合 RAW、重复性、固定坐标、Dark、Offset/Gain/Defect、采集模式、日志和版本信息逐步收敛。

## 统一诊断模型

```text
异常输入
→ 现象分类
→ 空间形态
→ 时间/重复性
→ RAW 是否存在
→ 校准前后对比
→ 采集/通信条件
→ 候选机制
→ 证据验证
→ Root Cause
```

### 根因置信度

- **Observed**：仅凭图像可以确认的现象。
- **Candidate**：根据现象形成的候选机制，尚无充分证据。
- **Confirmed**：有 RAW / 多帧 / 校准 / 日志 / 硬件或替换验证支持。

## A. 图像像素与局部缺陷

### 1. 坏点 / 黑点 / 白点

**现象**：固定位置出现异常单点或少量像素异常。

**优先检查**：
- 是否固定坐标；
- 多帧是否重复；
- RAW 是否存在；
- Dark 是否存在；
- Defect Template 是否覆盖；
- Offset / Gain / Defect 后是否消失。

**候选机制**：Bad Pixel、Defect Template、Offset/Gain、Sensor/Readout Hardware。

**结论边界**：单张图不能直接判定硬件坏点。

### 2. 坏点蔟

**现象**：相邻或局部区域存在多个异常像素。

**重点区分**：孤立 Bad Pixel 与连续区域/结构性异常。

**证据**：固定坐标、RAW、Dark、Defect Template、校准前后对比。

**候选机制**：Defect、局部 Sensor/Readout、Calibration Data。

### 3. 坏线

**现象**：一整行或一整列异常。

**重点**：先确认是图像现象还是固定 Read/Gate 结构相关异常。

**候选机制**：Bad Row、Bad Column、Read Channel、Gate Channel、Calibration、Hardware。

**禁止直接结论**：坏线 ≠ 通道异常。

## B. 规则性条纹与通道类伪影

### 4. 横条纹噪声

**现象**：沿水平方向形成条带。

**优先检查**：固定位置、是否贯穿整幅、RAW 是否存在、曝光条件变化、Dark/Offset。

**候选机制**：Bad Row、Readout、Gate、Offset、EMC/Interference、Hardware。

### 5. 横竖条纹

**现象**：同时出现水平与垂直规则条纹。

**重点**：先确认空间周期和固定坐标，再判断 Read/Gate 或其他干扰。

### 6. 等距竖条纹

**现象**：垂直方向出现近似固定周期的重复条纹。

**候选机制**：Readout/Channel、周期性干扰、采集或处理链。

**要求**：必须结合周期、RAW 和重复采集判断，不可仅凭外观判定“通道异常”。

### 7. Read 通道伪影

**现象标签**：疑似与 Readout/读出通道对应的规则异常。

**进入该分类的条件**：图像形态与 Readout 结构有明确对应关系，并有 RAW/重复性/位置证据支持。

**注意**：`Read channel artifact` 是机制候选/分类，不应在证据不足时作为最终 Root Cause。

### 8. Gate 通道伪影

**现象标签**：疑似与 Gate/行驱动结构对应的异常。

**要求**：需要固定行方向、位置规律或硬件/时序证据支持。

**注意**：横线本身不足以确认 Gate Channel。

### 9. 通道伪影 / 通道跌落

**通道伪影**：先作为候选分类，不作为单图直接根因。

**通道跌落**：需要结合通道映射、连续采集、RAW 数据及相关诊断证据确认。

## C. 图像统计与均匀性

### 10. 图像颗粒噪声

**现象**：随机颗粒状噪声明显增加。

**优先检查**：Dark、曝光条件、重复采集、剂量、模拟/数字噪声、环境干扰。

**候选机制**：Noise、Electronics、Exposure、EMC、Processing。

### 11. 加载 Gain 后图像灰度不均匀

**现象**：加载 Gain 后均匀性异常。

**重点检查**：Gain 数据来源、采集条件、Offset 状态、Gain Template、校准前后对比。

**原则**：Gain 异常不能直接等于探测器硬件异常。

### 12. 原始暗场图灰度值异常

**现象**：无曝光 Dark Image 的灰度分布异常。

**优先级高**：这是判断 Offset / 本底 / 采集链的重要证据。

**必须记录**：平均值、分布、固定区域、重复 Dark、曝光状态。

### 13. 本底跳动

**现象**：Dark/Base level 在重复采集之间明显变化。

**重点区分**：随机波动与持续漂移。

**候选机制**：Detector baseline、温度、电子噪声、供电、采集条件。

### 14. 本底漂移

**现象**：本底随时间持续变化。

**证据**：连续 Dark 序列、时间轴、温度/工作状态。

### 15. 曲线异常

**现象**：灰度 Profile / 特征曲线出现异常峰、谷、周期或趋势。

**原则**：先描述曲线形态，再映射到图像现象和候选机制。

### 16. 灵敏度偏低

**现象**：相同曝光条件下图像响应偏低。

**优先检查**：mA、kV、曝光实际执行、Gain、Detector 状态、灰度响应曲线。

### 17. 图像灰度值不随曝光剂量增加

**现象**：增加曝光剂量后灰度未按预期增加。

**优先检查**：实际 mA/kV、曝光是否生效、Detector 饱和、Gain、采集链、图像处理。

**注意**：不能仅凭最终图像判断是 Detector 灵敏度问题。

### 18. 饱和阶梯

**现象**：高灰度区域出现分级/阶梯状饱和表现。

**候选机制**：ADC/动态范围、曝光条件、处理或显示链。

**证据**：RAW 灰度范围、曝光参数、Histogram/Profile。

## D. 时序与残影

### 19. Ghost 残影

**现象**：前一幅或高剂量曝光内容在当前图像中残留。

**优先检查**：前一帧、当前帧、曝光剂量、间隔时间、连续采集序列。

**候选机制**：Lag、Detector Response、Dynamic Correction、Acquisition Sequence。

### 20. 过度带

**现象**：曝光相关区域出现异常过渡带。

**重点**：确认与曝光边界、动态响应、校正或处理是否相关。

### 21. 曝光行

**现象**：与曝光过程/行扫描时序相关的行方向异常。

**重点**：记录曝光时间、触发方式、异常行位置和 RAW。

## E. 几何、拼接与结构性伪影

### 22. 图像不规则伪影

**现象**：非规则、非周期的局部或大范围异常结构。

**原则**：不能因为“不规则”就归类为硬件。

**优先区分**：RAW、处理链、拼接、噪声、外部干扰。

### 23. 拼接错误

**现象**：图像块之间存在错位、接缝、重复或缺失。

**优先检查**：RAW 是否已异常、Tile/Frame 顺序、拼接参数、SDK/Processing。

### 24. 拉链线

**现象**：出现类似拉链/周期性接缝结构。

**候选机制**：拼接、Readout/Channel、Processing、固定结构。

### 25. 图像奇偶差异明显

**现象**：奇偶行/列或相邻采样结构之间响应差异明显。

**重点**：检查采样结构、Readout、Gain、校准和 RAW。

### 26. 按压伪影

**现象**：按压探测器后图像产生局部异常。

**优先检查**：异常是否与按压位置一致、是否可重复、释放后是否恢复。

**候选机制**：Mechanical / Sensor / TFT / Scintillator / Temporary Response。

## F. 电磁与外部干扰

### 27. EMC 干扰

**现象**：具有规则性、周期性或与设备/环境状态相关的干扰。

**优先验证**：
- 更换环境/电源条件；
- 关闭可疑干扰源；
- 重复采集；
- 对比 RAW/Dark。

**确认标准**：必须存在环境相关的可重复证据。

### 28. Microphony

**现象**：机械振动/声学或结构耦合导致的图像异常候选。

**验证**：改变机械/振动条件并重复采集。

## G. Calibration / Template 类

### 29. 栅纹无法去除

**现象**：校准后规则栅纹仍存在。

**重点**：确认 RAW 是否已有栅纹、Calibration Data 是否正确、Defect/Gain/Offset 是否有效。

**结论边界**：校准无法消除 → 提高 Hardware / Acquisition 候选权重，但仍需证据确认。

### 30. 黑斑

**现象**：较大区域的暗斑/黑色区域。

**优先检查**：RAW、Dark、固定位置、Defect、Gain、按压/机械因素。

## H. 通信与数据完整性

### 31. 丢包

**现象**：图像数据传输不完整或出现缺失。

**排查：
```text
Link
→ IP
→ Ping
→ TCP/UDP
→ Packet Capture
→ SDK
→ Image Assembly
```

**注意**：Ping 正常不代表没有 Packet Loss 或应用层传输异常。

## I. 探测器电源 / 指示灯 / 热状态

### 32. 平板不上电

**优先检查**：输入电源、线缆、供电状态、Power Board、内部电源域。

### 33. 平板指示灯异常

**重点**：记录灯状态、颜色、闪烁模式、发生时机，并与 Power/Communication/Ready 状态对应。

### 34. 探测器过热

**必须记录**：温度、环境、工作时间、连续曝光、散热状态。

**原则**：过热既可能影响图像，也可能影响稳定性；不能只从图像现象反推根因。

## J. Exposure / Generator

### 35. 内触发曝光不上图
### 36. 外触发曝光不上图
### 37. 软触发曝光不上图
### 38. AED 曝光不上图

统一判断：

```text
曝光是否真正发生？
→ Detector 是否进入正确状态？
→ Exposure Event 是否产生？
→ Image Acquisition 是否启动？
→ Wait Image 是否超时？
→ 数据是否传输？
→ SDK 是否收到图像？
```

不同触发方式必须单独记录，不能因为一种 Trigger 正常就认定所有 Trigger 正常。

### 39. 软触发曝光超时

重点错误事件：

```text
Evt_WaitImage_Timeout
```

必须保存：触发时间、Detector 状态、SDK Log、曝光状态、网络状态。

### 40. mA 过高 / 过低
### 41. kV 过高 / 过低

不要只记录软件设置值。

必须区分：

```text
Set Value
vs.
Actual Exposure
```

并结合图像灰度、剂量和 Generator 状态判断。

## K. Image Shift / 几何变化

### 42. Image Shift

必须比较：
- 正常参考图；
- 当前图；
- 固定结构/标志物位置；
- 是否随重启、安装、机械状态变化。

不要把几何偏移直接判断为 Pixel/Channel 故障。

# 单张异常图像的强制输出格式

以后上传一张异常图像，第一层输出必须按照以下格式：

```text
【图像现象】
例如：固定位置水平条纹

【可直接确认】
仅确认图像表现，不确认根因。

【图像特征】
方向：Horizontal
位置：固定 / 不固定 / 待确认
范围：局部 / 全幅 / 待确认
重复性：待确认

【优先候选】
1. Bad Row / Readout
2. Gate / Acquisition
3. Offset / Calibration
4. EMC / Interference
5. Hardware

【当前不能确认】
不能仅凭单张图确认 Channel / Gate / ADC / Hardware。

【需要补充】
RAW
Dark
连续多帧
固定坐标
Offset/Gain/Defect 结果
Detector SN
Firmware
SDK

【下一步】
先补证据，再进入 DecisionTree。
```

## 知识库准入规则

每获得一张新的异常图像，不是简单“保存图片”，而是建立一条知识记录：

```text
Image
+ Phenomenon
+ Product
+ Exposure Condition
+ RAW
+ Evidence
+ Candidate Causes
+ Verification
+ Root Cause
+ Final Resolution
```

只有完成验证的案例才能升级为：

```text
Confirmed Knowledge
```

未验证内容只能标记：

```text
Candidate
```

这样后续 AI 分析图像时，会优先匹配**视觉现象和证据特征**，而不是看到某种条纹就直接输出“通道异常”。
