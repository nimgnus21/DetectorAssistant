# Chat Template

> Module: Template
>
> Category: Instant Messaging

---

# Overview

This document provides standardized instant messaging templates for daily technical support.

These templates are designed for communication through Microsoft Teams, WeChat, DingTalk, KakaoTalk, Slack, WhatsApp, or similar messaging platforms.

Compared with EmailTemplate.md, these messages are shorter, more conversational, and suitable for real-time communication while maintaining a professional tone.

---

# Usage Principles

- Keep messages concise.
- One request per message.
- Use bullet lists whenever possible.
- Avoid long paragraphs.
- Request only the information needed for the current troubleshooting step.

---

# Template 1 - First Contact

Hello.

To help investigate the issue, could you please provide the following information?

• Detector Model

• Detector SN

• SDK Version

• Firmware Version

• Detector.log

• Brief description of the problem

Thank you.

---

# Template 2 - Request Detector.log

Could you please send us the latest **Detector.log**?

It will help us determine the cause of the issue more quickly.

Thank you.

---

# Template 3 - Request Images

Could you please provide:

• Original Image

• Corrected Image

• Screenshot of the acquisition software

Thank you.

---

# Template 4 - Request Network Information

Please check the following:

• Detector IP

• Computer IP

• Ping result

• Network cable connection

• Switch model (if applicable)

Thank you.

---

# Template 5 - Unable to Connect

Please confirm the following:

□ Detector powered on

□ Network cable connected

□ IP configuration correct

□ Detector interface screenshot

□ Detector.log

Thank you.

---

# Template 6 - Unable to Acquire Image

Please confirm:

□ Generator model

□ Trigger mode

□ Exposure parameters

□ Detector.log

□ Whether Evt_Image is received

Thank you.

---

# Template 7 - Calibration Failure

Please provide:

• Calibration type

• Detector.log

• Calibration images

• Error screenshot

Thank you.

---

# Template 8 - Firmware Upgrade

Please send:

• Current firmware version

• Target firmware version

• Detector SN

• Upgrade error screenshot

Thank you.

---

# Template 9 - License Issue

Please provide:

• Detector SN

• Detector.log

• License file (if available)

• Screenshot of the error

Thank you.

---

# Template 10 - Remote Support Invitation

Would it be convenient to arrange a remote support session?

Please prepare:

• Detector powered on

• Stable network

• TeamViewer / AnyDesk

• Administrator privileges

Please let us know your available time.

Thank you.

---

# Template 11 - Waiting for Customer Feedback

Just following up on this issue.

Have you had a chance to perform the requested test?

If so, please send us:

• Detector.log

• Test images

• Latest status

Thank you.

---

# Template 12 - Request OQC Information

Please provide:

• Detector interface screenshot

• Acquisition interface screenshot

• Detector front photo

• Detector rear photo

• Package label photo

• Firmware version

Thank you.

---

# Template 13 - Request Reproduction

To help us reproduce the issue, could you please provide:

• Step-by-step operation

• Frequency of occurrence

• Whether the issue happens every time

• Time when the issue occurred

Thank you.

---

# Template 14 - Issue Resolved

Thank you for your cooperation.

We are glad to hear the issue has been resolved.

If the problem occurs again, please send us:

• Detector.log

• Error screenshot

• Reproduction steps

Have a great day!

---

# Template 15 - Case Closed

As no further issues have been reported, we will close this support case.

If the issue reappears, please feel free to contact us again.

Thank you for your cooperation.
