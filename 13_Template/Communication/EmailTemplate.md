# Email Template

> Module: Template
>
> Category: Email Communication

---

# Overview

This document provides standardized email templates for customer support, technical communication, firmware verification, RMA processing, and project follow-up.

These templates are intended for daily communication between Field Application Engineers (FAEs), customers, distributors, and internal engineering teams.

---

# Usage Principles

Before sending an email:

- Use a clear subject.
- Keep the email concise and professional.
- Include all required technical information.
- Attach relevant logs and images.
- Clearly state the expected action.

---

# Template 1 - Initial Technical Support

## Subject

Technical Support Request – Detector Issue Investigation

---

Dear Customer,

Thank you for contacting us.

To help us investigate the issue, please provide the following information:

- Detector Model
- Detector Serial Number (SN)
- SDK Version
- Firmware Version
- Detector.log
- Problem Description
- Steps to Reproduce
- Original Image (if applicable)
- Screenshot of the Software Interface

Once we receive the above information, we will begin our analysis immediately.

Best Regards
