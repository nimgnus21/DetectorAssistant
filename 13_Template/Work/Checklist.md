# Overview

This document provides standardized checklists for common detector installation, commissioning, troubleshooting, maintenance, and return procedures.

The checklists are intended to help Field Application Engineers (FAEs) perform systematic inspections, reduce troubleshooting time, and ensure that important verification steps are not missed.

---

# Usage Principles

- Complete each checklist item before proceeding.
- Record abnormal findings immediately.
- Collect supporting evidence (logs, images, screenshots) whenever possible.
- Do not skip items unless confirmed as not applicable.
