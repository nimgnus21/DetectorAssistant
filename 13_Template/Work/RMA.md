# Overview

This document provides standardized templates for Return Material Authorization (RMA), including fault information collection, shipment preparation, receiving inspection, repair verification, and return confirmation.

It is intended for Field Application Engineers (FAEs), Quality Engineers, Production Engineers, and Technical Support Engineers handling detector repair and replacement.

This document standardizes the RMA workflow and ensures complete traceability throughout the repair process.

---

# Applicable Scope

This template applies to:

- Detector Hardware Failure
- Image Quality Failure
- Communication Failure
- Calibration Failure
- Firmware Failure
- Production Verification
- Warranty Repair
- Out-of-Warranty Repair
