>

# Overview

This document defines the standard terminology related to detector image acquisition, image processing, image quality evaluation, and image correction.

These terms are referenced throughout the DetectorAssistant knowledge base, including image troubleshooting, calibration, SDK documentation, failure analysis, and technical support.

---

# Image

## Definition

Digital image data acquired by the detector after X-ray exposure.

## Related Terms

- Raw Image
- Corrected Image
- Pixel

---

# Raw Image

## Definition

The original image acquired directly from the detector before any image correction.

## Characteristics

- Original detector output
- No Offset correction
- No Gain correction
- No Defect correction

## Typical Usage

Used for:

- Calibration
- Factory testing
- Image quality analysis
- Algorithm verification

---

# Corrected Image

## Definition

An image after Offset, Gain and Defect corrections have been applied.

## Purpose

Provide the final image for clinical or industrial use.

---

# Preview Image

## Definition

A compressed or scaled image used for quick display.

---

# Pixel

## Definition

The smallest image element representing one detector sampling point.

---

# Pixel Value

## Definition

The numerical intensity value assigned to a pixel.

## Characteristics

Represents detector response to X-ray exposure.

---

# Gray Value

## Definition

The brightness level of a pixel.

Higher values generally indicate stronger detector response.

---

# Bit Depth

## Definition

The number of bits used to represent each pixel.

## Common Values

- 12-bit
- 14-bit
- 16-bit

---

# Dynamic Range

## Definition

The range between the minimum and maximum measurable detector signal.

## Purpose

Determine the detector's ability to represent weak and strong signals simultaneously.

---

# Signal

## Definition

Useful detector response generated by X-ray exposure.

---

# Noise

## Definition

Random unwanted fluctuations appearing in image data.

## Typical Sources

- Electronic noise
- Thermal noise
- Readout noise
- Environmental interference

---

# Signal-to-Noise Ratio (SNR)

## Definition

The ratio between useful image signal and background noise.

## Purpose

Evaluate image quality.

Higher SNR generally indicates better image quality.

---

# Contrast

## Definition

The difference in gray value between adjacent image regions.

---

# Uniformity

## Definition

The consistency of pixel response under uniform exposure.

## Purpose

Evaluate detector calibration quality.

---

# Brightness

## Definition

Overall intensity level of an image.

---

# Histogram

## Definition

A graphical representation of the distribution of image gray values.

## Purpose

Evaluate exposure and image quality.

---

# Saturation

## Definition

A condition where detector output reaches its maximum measurable value.

## Characteristics

Pixel values can no longer increase.

---

# Underexposure

## Definition

Insufficient X-ray exposure resulting in low image signal.

---

# Overexposure

## Definition

Excessive X-ray exposure causing loss of useful image information.

---

# Artifact

## Definition

Any unwanted structure appearing in an image that does not represent the actual object.

## Common Types

- Line Artifact
- Ring Artifact
- Ghost Artifact
- Grid Artifact

---

# Ghost

## Definition

Residual image information remaining from previous exposures.

## Related Terms

- Image Lag
- Ghost Correction

---

# Image Lag

## Definition

Residual detector signal that persists into subsequent image acquisitions.

---

# Residual Image

## Definition

Visible image information remaining after exposure has ended.

---

# Line Artifact

## Definition

Abnormal horizontal or vertical lines appearing in an image.

## Typical Causes

- Gate Driver failure
- Readout failure
- Communication errors

---

# Banding

## Definition

Wide horizontal or vertical bands with abnormal brightness.

---

# Dead Pixel

## Definition

A pixel producing little or no usable signal.

---

# Hot Pixel

## Definition

A pixel continuously outputting abnormally high values.

---

# Defective Pixel

## Definition

A pixel that does not respond according to detector specifications.

---

# Image Uniformity

## Definition

The consistency of detector response across the entire image.

---

# Image Resolution

## Definition

The ability to distinguish fine image details.

## Related Terms

- Pixel Pitch
- Matrix Size

---

# Spatial Resolution

## Definition

The capability of the detector to distinguish closely spaced objects.

---

# Matrix Size

## Definition

The total number of image pixels expressed as rows × columns.

## Example

```
3072 × 3072

2048 × 2048
```

---

# ROI (Region of Interest)

## Definition

A selected image region used for analysis or processing.

---

# Window Width (WW)

## Definition

The range of gray values displayed.

---

# Window Level (WL)

## Definition

The center gray value of the displayed image window.

---

# Flat Field Image

## Definition

An image acquired using uniform X-ray exposure.

## Typical Usage

- Gain Calibration
- Detector Performance Evaluation

---

# Dark Image

## Definition

An image acquired without X-ray exposure.

## Typical Usage

- Offset Calibration
- Noise Analysis

---

# Image Correction

## Definition

The process of improving image quality using calibration templates.

## Typical Corrections

- Offset Correction
- Gain Correction
- Defect Correction
- Ghost Correction

---

# Offset Correction

## Definition

Correction used to remove detector background signal.

---

# Gain Correction

## Definition

Correction used to compensate for pixel sensitivity differences.

---

# Defect Correction

## Definition

Correction used to replace defective pixel values using neighboring pixels.

---

# Image Acquisition

## Definition

The process of receiving image data from the detector.

---

# Frame

## Definition

A single acquired image during an acquisition sequence.

---

# Continuous Frame

## Definition

An image acquired during continuous acquisition mode.

---

# Image Buffer

## Definition

Memory used to temporarily store image data before processing.
