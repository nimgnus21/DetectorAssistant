# ImageJ Plugins

## Scope

Plugins may extend analysis capability, but no plugin-specific detector diagnosis is considered a standard requirement unless its applicability has been validated for the product and image format.

## Usage Rule

1. Prefer built-in operations for standard inspection and measurement.
2. Record the plugin name and version when a plugin is used.
3. Preserve the original image and record any conversion or preprocessing.
4. Do not make a root-cause conclusion based only on plugin output.

## Evidence Requirements

When plugin output is used in a Case or escalation, retain:

- Original image
- Plugin name/version
- Input settings
- Output or screenshot
- Operator interpretation
