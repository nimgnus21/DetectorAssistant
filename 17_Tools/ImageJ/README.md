# ImageJ

## Purpose

用于探测器图像的形态比较、位置对比和基础测量，辅助判断异常是否固定、是否重复以及是否随采集条件变化。

## Use When

- 横纹/条带需要比较位置与重复性
- 固定异常与随机异常需要区分
- 多张图像需要进行形态或位置对比

## Output

- 对比截图或测量结果
- 异常位置/形态记录
- 与原始图像关联的分析结论

ImageJ 用于辅助分析，不替代已验证的根因判断或校正流程。
