# Offset Viewer FAQ

## What does an abnormal Offset pattern prove?

It proves an observed Offset characteristic only. Confirm the detector mode, calibration state, acquisition result and logs before assigning root cause.

## When should Offset data be preserved?

Before replacing templates, resetting the detector or repeating calibration after an unexplained failure.

## Can one Offset file represent every mode?

Do not assume so. Record the active product/application mode and calibration context for each analysis.

## What evidence should accompany an Offset analysis?

Keep the Offset source, observation screenshot/export, detector model, relevant mode, calibration state and corresponding test image/log when available.
