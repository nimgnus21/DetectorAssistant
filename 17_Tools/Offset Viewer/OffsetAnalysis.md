# Offset Analysis

## Purpose

Inspect Offset-related image data when calibration or image troubleshooting indicates a possible Offset abnormality.

## Procedure

1. Confirm the detector model, active mode and relevant calibration state.
2. Load the required Offset data using the applicable product workflow.
3. Inspect overall uniformity and localized or line-like abnormalities.
4. Compare affected and unaffected regions when possible.
5. Record the file source, mode, timestamp and observed characteristic.
6. Combine the result with calibration status, test images and logs before concluding root cause.

## Output

- Offset observation result
- Abnormal region/direction
- Supporting screenshot or export
- Related calibration/image evidence
