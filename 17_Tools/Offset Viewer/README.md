# Offset Viewer

## Purpose

用于辅助分析 Offset 图像或 Offset 相关异常，支持判断固定结构、非均匀性和校正方向是否需要进一步检查。

## Use When

- Offset generation 后需要复核结果
- 图像异常疑似与 Offset/校正相关
- 固定条带或坏线需要区分校正与其他方向

## Standard Output

- Offset 图像/截图
- 异常区域或模式说明
- 是否建议进入重新校正或进一步硬件分析

## Boundary

Offset Viewer 的分析结果是诊断证据，不单独等同于根因。
